## 📖 Overview

FlickWave is a front-end movie website that shows featured films in a full-screen slider, a grid of new releases and a carousel of the latest titles. It also includes login and registration pages and a newsletter sign-up. I built it to practise responsive layout, CSS styling and working with JavaScript libraries.

## ✨ Features

- Full-screen hero slider with autoplay, pagination dots and trailer buttons (Swiper.js)
- **Opening This Week** grid with 22 movie cards showing title, runtime and genre
- **Latest** carousel with autoplay and a layout that adapts to screen size
- Movie search box with suggestions
- Sticky header with a shadow on scroll and a mobile menu that opens and closes
- Login page and registration page (front-end design only)
- Newsletter subscription section
- Fully responsive for phones, tablets and desktops

## 🛠️ Tech stack

`HTML5` `CSS3` `JavaScript` `Swiper.js 8` `Boxicons` `Ionicons`

## 🚀 Run it locally

```bash
git clone https://github.com/M-Ubaid-Shaikh/flickwave.git
cd flickwave
```

Open `index.html` in your browser, or right-click it in VS Code and choose **Open with Live Server**. An internet connection is needed for the Swiper, Boxicons and Ionicons libraries.

## 🌐 Deploy

1. Push this repository to GitHub.
2. Import it on [vercel.com](https://vercel.com) and click **Deploy**. No build settings are needed.
3. Paste the live address into the **Live Demo** badge at the top of this README.
